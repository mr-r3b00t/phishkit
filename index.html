Why it's safe

🚫
No code runs. Email HTML renders in a sandboxed iframe with no scripts; PDFs render to canvas with JavaScript disabled.
📡
No phone-home. Remote images, fonts and trackers are blocked by default — opening a message can't confirm you read it.
🔗
Links can't bite. Every link is made non-clickable and listed with its true destination (gateway wrappers unwrapped).
📎
Attachments stay put. Embedded files never auto-open; dangerous types are flagged and saved as inert downloads.
🕵️
Threat triage. Each file gets a ✅ / ⚠️ / ⛔ verdict with itemised, plain-English findings.
💻
Yours alone. All parsing is client-side. No server, no account, no data ever leaves your machine.

These tools help you triage suspicious files — they reduce risk, they don't guarantee safety. A clean verdict is not permission to click links or open attachments you weren't expecting.
